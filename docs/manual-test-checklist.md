# Manual device checklist

Spec success criterion 7: on the phone, playback continues with the screen locked for at least 30 minutes, the notification controls work, and reopening the app resumes from the saved position (within one segment). Run this after changes to `src/playback/` or `android/.../narrator/`.

**Setup:** `npm run android:apk`, then install `android/app/build/outputs/apk/debug/app-debug.apk` (`adb install -r …`, or copy the file to the phone). Create a story with at least two analysed parts and open the reader.
